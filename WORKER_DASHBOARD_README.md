# Farm Worker Dashboard - لوحة تحكم العامل

## Overview - نظرة عامة

The Farm Worker Dashboard is a simplified interface designed specifically for farm workers to perform daily operational tasks without needing access to the complex administrative features of the main system.

لوحة تحكم العامل هي واجهة مبسطة مصممة خصيصاً لعمال المزرعة لأداء المهام التشغيلية اليومية دون الحاجة للوصول إلى الميزات الإدارية المعقدة للنظام الرئيسي.

## Features - الميزات

### 1. Feeding Management (إدارة التغذية)
- **Feed Input Registration**: Record incoming feed supplies
- **Feed Distribution**: Distribute feed to barns with automatic stock tracking
- **Feed Types**: Support for concentrated feed (14%, 16%, 21%) and roughage (hay, straw)

#### تسجيل دخول العلف
- تسجيل المواد العلفية الواردة
- أنواع العلف المركز: 14%، 16%، 21%
- العلف الخشن: دريس، تبن

#### صرف التغذية
- توزيع العلف على الحظائر
- تتبع تلقائي للمخزون
- تسجيل الكميات والتواريخ

### 2. Medicine Management (إدارة الأدوية)
- **Medicine Input**: Register new medicine inventory
- **Treatment Distribution**: Apply treatments to individual animals
- **Vaccination Programs**: Apply vaccines to entire barns
- **Prescription Tracking**: Record prescription numbers and dosages

#### تسجيل دخول الأدوية
- إضافة أدوية جديدة للمخزون
- تحديد نوع الدواء (علاج أو تحصين)
- تسجيل الكميات وتواريخ الانتهاء

#### صرف الأدوية والتحصينات
- العلاج: للحيوانات الفردية بأرقام الإذن
- التحصين: للحظائر الكاملة
- تتبع الجرعات والوصفات

### 3. Animal Management (إدارة الحيوانات)
- **New Animal Registration**: Add new animals to the system
- **Weight Recording**: Track animal weights over time
- **Weaning Records**: Document weaning processes

#### تسجيل حيوان جديد
- إدخال بيانات الحيوانات الجديدة
- تحديد النوع: ذكر، أنثى، مولود
- تسجيل الأوزان والتواريخ

#### تسجيل الأوزان
- متابعة أوزان الحيوانات
- تسجيل دوري للنمو
- تتبع الأداء

#### سجل الفطام
- توثيق عمليات الفطام
- نقل الحيوانات بين الحظائر
- متابعة النمو بعد الفطام

## User Access - الوصول للمستخدم

### Login Credentials - بيانات الدخول
- **Email**: worker@farm.com
- **Password**: demo123
- **Role**: Farm Worker (عامل المزرعة)

### Automatic Redirection - التحويل التلقائي
Workers are automatically redirected to their specialized dashboard when they log in, ensuring they only see relevant functions for their role.

يتم تحويل العمال تلقائياً إلى لوحة التحكم المخصصة لهم عند تسجيل الدخول، مما يضمن رؤيتهم للوظائف المناسبة لدورهم فقط.

## Data Synchronization - مزامنة البيانات

All worker actions are automatically synchronized with the main admin dashboard:

جميع إجراءات العامل تتم مزامنتها تلقائياً مع لوحة التحكم الإدارية الرئيسية:

- **Feed movements** are recorded in inventory
- **Medicine usage** updates stock levels
- **Animal records** are integrated with the main system
- **All activities** are timestamped and attributed to the worker

## System Integration - التكامل مع النظام

The worker dashboard integrates seamlessly with:
- Stock Management System
- Animal Records
- Health Records
- Feeding Schedules
- Barn Management

## Security & Permissions - الأمان والصلاحيات

- Workers can only access their designated functions
- No access to financial data or sensitive reports
- All actions are logged with timestamps
- Role-based access control prevents unauthorized access

## Mobile Friendly - متوافق مع الهواتف

The dashboard is fully responsive and optimized for:
- Mobile phones
- Tablets
- Desktop computers
- Touch-screen interfaces

## Support - الدعم

For technical support or questions about the worker dashboard, contact the farm administrator or system support team.

للدعم الفني أو الاستفسارات حول لوحة تحكم العامل، تواصل مع مدير المزرعة أو فريق دعم النظام.
